## Live Events

Events can begin without turning into a wall of chat.
The announcement appears **at the top of your screen**, with the important details in one place.
Watch Discord for the full event notice, then get online while it is active.

*If it was not announced, it is not live yet.*

### 🎁 Crate Key Rain

**Mysterious Crate Keys** fall into the event area for players to collect.
Every key you reach is a real key — keep it, trade it or open it with `/crate`.
The event announcement tells you where to go and when the drop begins.

*Look up. Move fast. Somebody else already saw that key.*

### ✨ Skyburst

The sky turns into the event.
Layered bursts, colour and sound fill the area for a server-wide spectacle.
There is nothing to configure and no menu to learn: be online and watch it happen.

*Some events pay. Some events simply refuse to be ignored.*

## Joining an Event

1. Read the **in-game banner** or Discord announcement.
2. Join using the normal Java or Bedrock address.
3. Follow the stated location, start time and rules.
4. Stay until the end — an event can change while it is running.

Event-specific rewards and restrictions are always stated in the announcement.
This page never promises an unannounced reward, schedule or start time.

**See you in the next event.**
